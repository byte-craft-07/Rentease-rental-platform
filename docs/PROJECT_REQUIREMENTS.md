# Project Requirements

## Context

Students and working professionals frequently relocate for education or jobs. Buying furniture and appliances creates high upfront costs, maintenance responsibilities, and relocation challenges. RentEase provides monthly rental access to essential home products with flexible tenure, delivery, pickup, and maintenance support.

## User Roles

- Customer
- Admin
- Vendor or inventory operator

## Customer Features

- Register and login.
- Browse products by category.
- Filter furniture and appliances.
- View product details:
  - Monthly rent
  - Security deposit
  - Rental tenure options
  - Availability
  - Delivery eligibility
- Add products to cart.
- Update/remove cart items.
- Checkout with delivery date and location.
- View active rentals.
- Extend or schedule return for active rentals.
- Request maintenance support.
- View rental history.

## Admin / Vendor Features

- Manage users.
- Add and manage product inventory.
- Set rental pricing, deposit, and tenure options.
- Manage product availability.
- Manage delivery and pickup schedules.
- Monitor orders and rentals.
- Handle maintenance requests.
- Track returns and damages.
- Handle disputes and damage claims.
- Manage service areas.
- Generate reports and analytics.
- View audit trail for admin and vendor actions.

## Non-Functional Requirements

- Page load target under 3 seconds for common views.
- Secure login and payment-ready architecture.
- Accurate inventory tracking.
- Mobile-first, simple user interface.
- Scalable multi-city structure.

## KPIs

- Active rentals.
- Monthly recurring revenue.
- Product utilization rate.
- Customer retention rate.
- Maintenance request resolution time.
